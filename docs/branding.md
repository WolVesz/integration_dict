# Platte River Power Authority branding

Source: [Platte River Power Authority branding guidelines, October 2023](https://prpa.org/wp-content/uploads/2023/10/2023-Branding-guidelines_FINAL.pdf), page 10, published color palette. The frontend uses Arial and the corresponding palette tokens in `frontend/src/styles/tokens.css`.

This implementation uses the company name as text. It does not copy, redraw, or imply approval of the official logo. Obtain the company's approved logo asset and permission for the specific use before adding one or using it externally. Published guidelines alone are not logo-use authorization. This source-code theme is a draft application of the palette, not a claim of corporate design approval.

Check text/background contrast, keyboard focus, color-independent status labels, and mobile layouts when changing tokens. Bright accent colors need dark text or a darker accessible variant; a brand swatch is not automatically accessible for small white text.
